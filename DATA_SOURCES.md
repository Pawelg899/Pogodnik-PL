# Źródła
IMGW-PIB: dane publiczne, wymagane oznaczenie źródła i przetworzenia.
TSP: model IMGW, co 10 min, do 1 h, 1 km; wejścia obejmują PERUN, POLRAD i Meteosat.
Open-Meteo: dane modelowe; darmowe API jest niekomercyjne, CC BY 4.0.
RainViewer: radar; darmowy Weather Maps API dla użytku osobistego/edukacyjnego/małych projektów, wymagana atrybucja.
Nie sumujemy niezależnie PERUN/POLRAD/TSP, bo TSP już korzysta z tych źródeł.
